# SlashPeak

**The AI DBA for BigQuery.** See where every dollar goes, catch cost spikes early, and ship fixes as pull requests.

- **Cost analytics.** Spend by project, team, user, table and query.
- **Ranked savings.** Every finding has a monthly dollar estimate, so you fix the biggest one first.
- **Cognis AI DBA.** Opens the GitHub or dbt pull request for the fix. An owner approves it.

Read-only, metadata-only access. SlashPeak never reads your table data. 30-day free trial.
